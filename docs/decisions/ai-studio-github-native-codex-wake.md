## Alternatives and consequences

A desktop heartbeat retains dependence on an open local app. A PAT or direct
binary workaround introduces credential/security authority. Combining agent
and acceptance/write roles loses independent review. Separate jobs/artifacts
cost latency but retain inspectable evidence and token isolation.

Strict contracts can stop ambiguous tasks. Interrupted publication requires
reconciliation. Offline fixtures prove guard behavior only. Independent acceptance,
explicit exact-SHA merge, secret confirmation, task-scoped paid authority,
activation and one bounded live proof remain separate gates. General future-loop
authority and reviewer transition require later accepted decisions.
